# LinkHarvest Enterprise AI - Portal Web Platform (v5.5)

An elite, server-side data intelligence and candidate sourcing application built using an asynchronous Python server environment, integrated headless background workers, and dynamic large language models (LLM) orchestration layers. 

## 🏗️ Core Architecture Framework
* **Application Framework Backend:** FastAPI (Asynchronous ASGI server layer)
* **Browser Automation Framework Worker:** Playwright (Headless Chromium engine context mapping)
* **Generative Core Logic Brain:** Google GenAI Framework (Gemini 2.5 Flash API text stream parsing platform)
* **Document Compilation Graphics Engine:** ReportLab (Programmatic SimpleDocTemplate data table grid canvas)

## 🌐 Workflow Sourcing Mechanics
1. **Headless Stream Traversal:** The portal interface receives structural profile URL addresses via a secure multi-line queue dashboard. Playwright initializes a headless browser container context in the background, intercepts the webpage layouts utilizing active user cookies, and copies the clean rendering text string map out of active memory.
2. **Context-Aware AI Interpretation:** The raw text chunk stream is compiled and securely passed to the Gemini API utilizing a hidden corporate candidate assessment prompt template. The LLM processes the messy text map exactly like an expert researcher, instantly mapping out specific data variables.
3. **Programmatic Report Printing:** The clean, parsed dataset values are fed directly into the ReportLab compiler engine, which mathematically structures table padding and paragraph leading boundaries to output a high-fidelity corporate candidate dossier report PDF.
4. **Compressed File Streaming:** For single target profiles, the application delivers a direct browser `FileResponse` download. For bulk multi-link candidate campaigns, the backend loops sequentially, compresses the dossier PDFs inside an isolated directory, and exports a unified `.zip` archive file instantly onto the client taskbar Downloads tray.

## 🛠️ Local System Installation Guide
1. Initialize Python virtual environment: `python -m venv venv`
2. Activate environment parameters: `venv\Scripts\activate` (Windows)
3. Download required application stack dependencies: `pip install -r requirements.txt`
4. Deploy local background Chromium automation components: `playwright install chromium`
5. Fire up the central server infrastructure: `python app.py`
6. Access local dashboard view link: `http://127.0.0.1:8000`
